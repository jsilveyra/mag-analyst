Hysteretic tab — field renames + bound-default rework

Three changes, all Hysteretic tab: (1) rename JsField_2..6 and the 10 *Field_2 bound fields to the _JA names you asked for; (2) stop setting bounds as a side effect of "Retrieve seeds" — they're populated by default instead; (3) new defaults: Ms lower bound = the data's tip magnetization (Mtip) instead of -Inf, and a/k lower bounds = 0 instead of -Inf.

src/Hysteretic/HystereticUtils.m and src/Hysteretic/JAFitUtils.m are already updated (plain src/ files, no port needed) — this guide is only the app.mlapp/app_exported.m side.

Part A — Design View: rename 15 fields

Unlike the Stage-1 guide, this is renaming, not recreating — much simpler. In the Component Browser, select each field and use its rename action (double-click the name, or right-click > Rename). App Designer's rename is a smart rename: it updates every reference to that component inside app.mlapp itself automatically (createComponents, properties block, and any callback/method body you've written directly in the app class) — so you don't need to hand-edit the project-save/load or Playground-copy code that references these fields elsewhere in the file; renaming should take care of it. (It can't reach into HystereticUtils.m since that's a separate file — already handled directly, see above.)

Naming check: the Input tab already has fields named HTipField / MTipField (capital T, "Field" suffix) showing the same tip values. MATLAB property names are case-sensitive, so Htip / Mtip (lowercase t, no suffix) are distinct identifiers — grepped the whole file to confirm neither name is used anywhere yet. No collision, safe to use.
