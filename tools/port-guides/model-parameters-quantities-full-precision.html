Full precision for Model-Retrieved Parameters & Calculated Quantities

You'd flagged before that these two read-only Anhysteretic tables need full precision, and I'd only fixed their display formatting last time (6 sig figs instead of 4 decimals) — not the underlying gap. Two separate problems, both fixed here:

  • Step 1: ExportParametersButtonPushed (the "Export parameters" button, Output tab) built its report by re-parsing the tables' displayed text with str2double — for all three sections (Fitted Parameters, Model-Retrieved Parameters, Calculated Quantities). Now reads straight from the full-precision source instead: app.fitted_parameter_values for the Value column, and app.magnetic_parameters.{Ms,alpha,a,dimensionless_alphaMs,density_product,Hk, initial_relative_magnetic_permeability} (already full double precision, recomputed on every calculate/fit) for the two read-only tables. The report's own printed precision (%0.4f/%0.4e, a deliberate choice for a human-readable file) is unchanged — only the number feeding into it is now correct.
  • Step 2: gives TableParameters and TableQuantities the same click-to-reveal-full-precision behavior TableFittedParameters already has — select a cell to see its exact value, click elsewhere to return to the compact 6-sig-fig display. Two brand new callbacks (TableParametersCellSelection, TableQuantitiesCellSelection) since neither table had a CellSelectionCallback before.

Part A — Design View: add the two new callbacks first

App Designer blocks typing brand-new (non-callback) methods directly into the Code View callbacks section — same restriction that blocked reprocess_dataset earlier. These two are real callbacks though, so add them the normal way:

  1. Select TableParameters in the Component Browser, go to its Callbacks tab, add a new CellSelectionCallback and name it exactly TableParametersCellSelection. This creates an empty stub in Code View.
  2. Do the same for TableQuantities: new CellSelectionCallback named exactly TableQuantitiesCellSelection.

        % Cell selection callback: TableParameters
        function TableParametersCellSelection(app, event)
            if isempty(event.Indices)
                return
            end
            row = event.Indices(1,1);
            col = event.Indices(1,2);
            if row > height(app.TableParameters.Data) || isempty(app.magnetic_parameters) || row > numel(app.magnetic_parameters.Ms)
                return
            end
            app.init_parameters_table(false);
            switch col
                case 2
                    app.TableParameters.Data.Ms_col{row} = sprintf('%.16g', app.magnetic_parameters.Ms(row));
                case 3
                    app.TableParameters.Data.alpha_col{row} = sprintf('%.16g', app.magnetic_parameters.alpha(row));
                case 4
                    app.TableParameters.Data.a_col{row} = sprintf('%.16g', app.magnetic_parameters.a(row));
            end
        end

        % Cell selection callback: TableQuantities
        function TableQuantitiesCellSelection(app, event)
