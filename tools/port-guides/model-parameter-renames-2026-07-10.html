How to rename a component in App Designer

  1. Open app.mlapp in App Designer (Design View or Code View — the Component Browser tree is visible in both).
  2. Find the component in the Component Browser tree (use the row/column hints below, or click the component on the canvas — Design View makes this easiest since you can click directly on the label/field on screen).
  3. Double-click the component's name in the tree (or right-click → Rename), type the new name, press Enter.
  4. Repeat for all 19 rows below, then save.
