Fix: general-helpers methods block needs to be public too

Same underlying cause as the last fix, but for methods instead of properties: Cannot access method 'format_short' in class 'app' — AnhystereticUtils is a separate class, and format_short (like write_message, import_data, plot_input, apply_axis_scale, axis_scale_has_x, fit_stop_output_fcn, format_engineering, format_thousands_only) all live in the big methods (Access = private) block that starts right after the properties block you just fixed — so they're just as invisible to AnhystereticUtils as the properties were.

This is the file's first methods block (general helpers — file dialogs, formatting, plotting, import). There are two other blocks later in the file also marked Access = private (UI callbacks, and createComponents) — leave those two alone, nothing in AnhystereticUtils.m calls into them, and callbacks/createComponents don't need to be reachable from outside the class anyway. Only this first block, which holds the shared helpers, needs to widen.

Step 1. Change the first (general-helpers) methods block from private to public

Find this in Code View — right after the properties block you just fixed, marked by the "Safe file & folder helpers" comment
    methods (Access = private)
        %% =====================================================
        %  Safe file & folder helpers (cancel-safe, portable)
Do NOT change the other two "methods (Access = private)" blocks further down the file (the UI callbacks block, and createComponents) — only this first one.
Replace with
    methods (Access = public)
        %% =====================================================
        %  Safe file & folder helpers (cancel-safe, portable)

After saving, tell Claude — it will regenerate app_exported.m and this time run the app all the way through startupFcn (not just check it constructs) in matlab -batch before you launch it yourself again. If another private property/method turns up the same way, it means something in the extracted code reaches further than these two blocks — Claude will trace it the same way as these fixes rather than guessing.
