Full precision for cross-tab seed transfer (Anhysteretic → Hysteretic / Playground)

Root cause: get_first_anhysteretic_seeds read Ms/alpha/ a from the Anhysteretic tab's TableParameters displayed text (a 6-sig-fig rendering) instead of the full-precision app.magnetic_parameters that backs it — so both the Hysteretic tab's "Retrieve seeds" button and the Playground tab's "Retrieve parameters" button only ever imported the on-screen precision, not the true value. Same root cause as the two fixes from last time, just a third consumer of the same stale pattern.

Already fixed directly (plain src/ files, no port needed): AnhystereticUtils.get_first_anhysteretic_seeds now returns full-precision doubles read straight from app.magnetic_parameters.Ms(1) / app.magnetic_parameters.alpha(1) / app.magnetic_parameters.a(1) instead of parsing table text, and HystereticUtils.retrieve_ja_seeds updated to match (uses the numeric values directly for the fields, and a separate AnhystereticUtils.format_sigfigs call only for the write_message log text — the log message you see is unchanged, only the stored seed is now correct).

Checked for any other place that reads these tables' displayed text the same way — this was the only remaining one.
