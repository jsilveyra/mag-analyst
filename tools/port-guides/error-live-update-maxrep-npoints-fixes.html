  • Deleting the two orphaned callbacks (InputAxisScaleDropDownValueChanged, InputAxisScaleDropDownValueChanged2): App Designer protects any function it once generated as a component callback from plain text deletion in Code View, even after it's been unwired — that's the "blocked" behavior you're hitting.
