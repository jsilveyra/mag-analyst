Anhysteretic tab — report χᵢₙ instead of μrᵢₙ

Both the per-component quantity (previously "μrᵢₙ ᵢ" in the TableQuantities column) and the total quantity (previously the murinField display next to "Js [T]") now report χᵢₙ (initial susceptibility) instead of μrᵢₙ (initial relative permeability). The μrᵢₙ computation itself (MagneticParameters.murin / get_murin) is kept, not deleted — it's just no longer wired to the UI. A new MagneticParameters.chi_in_total property (= sum(chi_in)) backs the total-field display; the per-component chi_in property already existed (it was computed but unused before this change).

src/Anhysteretic/MagneticParameters.m and src/Anhysteretic/AnhystereticUtils.m are already updated (plain src/ files, no port needed) — this guide is only the app.mlapp/app_exported.m side.

Part A — Design View: rename 2 components

In the Component Browser, select each field/label below and use its rename action (double-click the name, or right-click > Rename). App Designer's rename is a smart rename: it updates every reference to that component inside app.mlapp automatically (createComponents, the properties block, and the TableQuantitiesCellSelection/export code you'll edit by hand in Part C) — so you only need to do the renames here, not hunt down every reference yourself.

Part B — Design View: update displayed text (Inspector)

  1. Select chiinLabel (the renamed label) in the Component Browser. In the Inspector, set its Text property from μrᵢₙ to χᵢₙ.
  2. Select TableQuantities in the Component Browser. In the Inspector, edit the ColumnName property: the 5th (last) entry changes from μrᵢₙ ᵢ to χᵢₙ ᵢ. The other four entries ("Component", "αᵢ⏐Msᵢ⏐/(3aᵢ)", "NᵢkвT [J/m³]", "Hkᵢ [A/m]") are unchanged.

Part C — Code View: 2 edits

Code edit 1. TableQuantitiesCellSelection(app, event) — full-precision reveal on cell click

This is the "click a table cell to see full precision" pattern (CLAUDE.md §8) — the table var name (chi_in_col) must match what AnhystereticUtils.init_quantities_table now uses, already updated in AnhystereticUtils.m.

Find this in Code View
        % Cell selection callback: TableQuantities
        function TableQuantitiesCellSelection(app, event)
            if isempty(event.Indices)
                return
            end
            row = event.Indices(1,1);
            col = event.Indices(1,2);
            if row > height(app.TableQuantities.Data) || isempty(app.magnetic_parameters) || row > numel(app.magnetic_parameters.dimensionless_alphaMs)
                return
            end
            app.init_quantities_table(false);

                case 4
                    app.TableQuantities.Data.Hk_col{row} = sprintf('%.16g', app.magnetic_parameters.Hk(row));
                case 5
                    app.TableQuantities.Data.initial_relative_magnetic_permeability_col{row} = sprintf('%.16g', app.magnetic_parameters.initial_relative_magnetic_permeability(row));
            end
        end
