Step 1. Mtip → ValueDisplayFormat = '%.5e'

Hysteretic-fitting tab, Component Browser → Mtip → Inspector (Design View — this is a component property, not reachable from Code View)

Mtip is the measured-data tip magnetization shown on the Hysteretic tab; it currently displays with %.6g (plain 6-significant-figure) formatting. Change it to scientific notation with 5 decimal places, matching the pattern already used for alpha's field (JsField_11, ValueDisplayFormat = '%.5e') elsewhere in the app.
