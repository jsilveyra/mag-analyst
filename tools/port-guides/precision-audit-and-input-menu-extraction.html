Precision audit fixes + Menu/Input tab extraction — 21 edits

Two independent bodies of work, bundled into one guide since neither touches the other's lines:

  • Part 1 (steps 1-5): the precision-audit follow-up from last time -- implements the previous guide's "Part D" (table display polish) as Code View property assignments since ColumnFormat wasn't in your Inspector, and fixes a real precision-loss bug the audit found in the Anhysteretic tab's TableFittedParameters bounds columns (lower/upper bound for Hcr/m/Hx) -- same bug class as the original Hysteretic one, now fixed with the same "full precision stored, 6-sig-fig display, reveal on click" pattern. This was the only remaining precision gap found in the whole app.
  • Part 2 (steps 6-21): finishes extracting business logic out of app_exported.m for the Menu (Open/Save/Save As) and Input tab, mirroring the Anhysteretic/Hysteretic/Playground extractions from earlier sessions. Three new plain src/ files are already created and need no port (src/Menus/MenuUtils.m, src/Common/FileDialogUtils.m, src/Input/InputUtils.m) -- this part of the guide is only the thin delegators left behind in app_exported.m, plus one new method (calculate_plot_and_refresh_hysteretic) needed so the Menu's "Open project" can trigger the same recalculation a manual "Calculate & Plot" click does, and one new shared method (reprocess_dataset) that de-duplicates logic that was previously copied identically across three separate Input-tab callbacks.

Step 4. TableFittedParametersCellEdit — extend to lower/upper bound columns (3, 4), not just Value (2)

Root fix for the Anhysteretic table's bounds: previously lb/ub were re-derived from the table's DISPLAYED text every time update_components ran, so once the display was reformatted to 6 sig figs, that truncated text became the real bound on the next fit. Now app.lb/app.ub are the source of truth (set once in init_components, updated only here on an actual edit), and the table is purely a rendering of them -- same architecture as the Value column's fitted_parameter_values.

        function TableFittedParametersCellEdit(app, event)

                return

            else

                update_components(app);
            end
            app.refresh_table_value_display();
        end
