High-precision numeric fields — remaining tabs

Extends the Hysteretic-tab precision fix to Input, Anhysteretic, and Playground. Four kinds of change, roughly in order of manual effort:

  • Part A (heaviest): 11 fields are currently plain text edit fields with no separate precision storage — same category of fix as the original Hysteretic bug. All 11 are read-only displays (Input's Htip/Mtip mirrors, Anhysteretic's Js/murin/ error, Hysteretic's error) except the 5 Playground JA-parameter fields (JsField_9-13 = Ms/a/alpha/c/k), which are user-editable exactly like the Hysteretic tab's Ms_JA etc. were before that fix. Same recipe as before: delete, add a Numeric Edit Field in the same cell, rename back to the original name.
  • Part B: 9 fields in the Playground tab are already Numeric Edit Fields (they always stored full precision — no bug there) but have no explicit ValueDisplayFormat, so they were falling back to MATLAB's default (%11.4g, 4 significant digits). Pure property tweak, no recreation needed.
  • Part C: 4 "Rel. tolerance" fields already show scientific notation but at only 1 significant digit (%.0e), and a copy/paste artifact left a stray newline in 3 of them (%.0e\n) — bumping to %.5e (6 sig figs) fixes both.
  • Part D: the 3 Playground tables (Minor-loop tip, Degaussing amplitudes, Harmonics) were already safe — their Data is a plain numeric array with no string round-trip, so there was never a precision-loss risk there. This is a pure display polish (ColumnFormat), optional but cheap.

All the accompanying code changes in AnhystereticUtils.m, PlaygroundUtils.m, and HystereticUtils.m are already applied directly (plain src/ files, no port needed). This guide is only the app.mlapp/app_exported.m side.

Code edit 2. TableFittedParametersCellSelection — reveal full precision on select for ALL rows (Hcr/Hx too, not just m)

Previously only m-rows revealed full precision on click; Hcr/Hx rows always showed the truncated display even while editing. Dropping the is_m_row condition extends the same behavior to every row.
