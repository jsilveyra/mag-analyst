Step 4. Make the Anhysteretic tab's grid checkboxes apply the same detailed (major+minor) grid as Hysteretic/Playground, instead of only patching YMinorGrid

Root cause of "unticking/reticking or Calculate&Plot changes the shown grid inconsistently": the current callbacks only ever restore YMinorGrid, never XMinorGrid, so the grid a checkbox toggle produces (Y-minor-only) differs from what a fresh plot produces (no minor grid at all, since Plotter.plot_M only toggled the major grid). Both call sites now go through the same app.apply_detailed_grid helper already used by the Hysteretic and Playground tabs, so the result is identical regardless of which one triggers it.

Find this in Code View
        % Value changed function: ShowgridCheckBoxM
        function ShowgridCheckBoxMValueChanged(app, event)
            grid(app.AxesM,"off");
            if(app.ShowgridCheckBoxM.Value == 1)
                grid(app.AxesM,"on");
                app.AxesM.YMinorGrid = 'on';  % Restore minor grid explicitly (grid on does not re-enable it)
            end 
        end

Part B — ColorDialog.mlapp (a separate App Designer file: src/Anhysteretic/ColorDialog.mlapp)

Step 6. Fix the property-name typo that silently breaks the popup's close (X) button

Root cause: the close handler references app.MainApp.SetColorsButton (capital "C"), but the actual button on the main app is named SetcolorsButton (lowercase "c") — MATLAB property names are case-sensitive, so this throws an error every time the window is closed via the X button, which aborts the callback before it reaches delete(app). That's why the window never actually closes.

Find this in ColorDialog.mlapp's Code View
        % Close request function: UIFigure
        function UIFigureCloseRequest(app, event)
            app.MainApp.SetColorsButton.Enable = 'on';

            delete(app)
        end
Replace with
        % Close request function: UIFigure
        function UIFigureCloseRequest(app, event)
            app.MainApp.SetcolorsButton.Enable = 'on';

            delete(app)
        end
