# Theme

Reserved for the app's visual-theme system (colors/fonts/line widths via
`theme_palette`/`apply_theme`).

As of 2026-07-06, `app_old.mlapp`/`app_old_exported.m` predate this system —
it currently exists only in `new/app_exported.m`. When the newer version is
merged into `app_old`, its theme methods should be extracted into this
folder rather than left inline.
